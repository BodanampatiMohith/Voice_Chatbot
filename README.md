# Voice-Enabled Chatbot Using Speech Recognition and Deep Learning

A Streamlit university-information chatbot that transcribes recorded speech locally with Vosk and classifies questions with a trained TensorFlow/Keras Bi-LSTM. Text entry is available as a fallback. No hosted language model, API credential, or online speech-recognition service is used.

## Features

- 18 original intents with 40 distinct utterances and three response variants per intent.
- Browser microphone input through `st.audio_input`, normalized to 16 kHz mono PCM WAV and transcribed offline.
- First use downloads `vosk-model-small-en-us-0.15` to `model/vosk/`, which is excluded from Git.
- Genuine Embedding/Bi-LSTM intent classifier, confidence threshold, uncertainty fallback suggestions, top-three scores, history, and clear-chat control.
- Stratified 70/15/15 evaluation, train-only tokenizer and augmentation, TF-IDF + Logistic Regression baseline, and generated metrics/plots.

Intent boundaries are stored with each class in `dataset/intents.json`. Tuition and academic charges are `fees`; accommodation and residence are `hostel`; class schedules are `timetable`; exams and results are `examinations`; university buses and routes are `transport`.

## Local setup

Use Python 3.11, as specified in `runtime.txt` and required by the pinned TensorFlow release.

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train.py
python test_chatbot.py
streamlit run app.py
```

Training saves the Keras model, tokenizer, label encoder, test metrics, confusion matrix, and training history in `model/`. It saves training curves, confusion-matrix, and baseline-comparison plots in `report/`. Only the training partition is augmented or used to fit the tokenizer; results are measured on an untouched stratified 15% test partition.

Vosk needs internet access for its first model download only. After the model has been downloaded, transcription runs offline. Text entry does not need a microphone.

## Deploy to Hugging Face Spaces

1. Create a Space at [huggingface.co/new-space](https://huggingface.co/new-space), choose **Streamlit** as the SDK, and select CPU hardware.
2. Clone the new Space repository and copy this project into it, or set its Git remote for this project.
3. In a Python 3.11 environment, run `pip install -r requirements.txt`, `python train.py`, and `python test_chatbot.py`. Confirm the regenerated label encoder has all 18 dataset intents.
4. Commit the generated trained artifacts so the Space can load the model. Do not commit `.venv/`, credentials, recordings, or `model/vosk/`; the Space downloads Vosk on first use.

```powershell
git add app.py train.py test_chatbot.py src dataset report model requirements.txt runtime.txt README.md .gitignore .streamlit
git commit -m "Build offline voice-enabled university chatbot"
git push
```

The YAML header above declares the Streamlit SDK, pinned SDK version, and application entry point. After the Space build succeeds, visit its URL, grant microphone permission, and test voice and typed queries. **Deployment link: not deployed yet.**

## Evaluation and limitations

No performance numbers are asserted in advance. The actual held-out scores, per-intent classification report, confusion matrix, history, and baseline comparison are generated by `train.py`. Existing saved artifacts in this workspace predate the 18-intent dataset and must be regenerated before deployment.

This compact educational dataset is not an official university source. Closed-set intent classification can misclassify unfamiliar questions, Vosk primarily recognizes US English, and answers should be checked against current university notices.
